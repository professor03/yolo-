# 已知限制與待辦

此版本是可供本機展示的研究原型。

## 功能界線

- YOLOv8 預訓練人物偵測不等同學生動作辨識；沒有驗證過的專注度指標。
- LearnSight 只讀聚合人數；source_id 尚未用來隔離同步資料。
- 聚合資料可能過期，未加入來源斷線與訊號有效期限判定。
- 時段存記憶體、重啟遺失，尚未綁定個別使用者。
- 相機「切換／停止」部分歷史 API 只回傳狀態文字，不能視為已驗證的控制功能。
- 舊即時串流、進階 ML 與多攝影機模組未納入本次公開 demo 的功能保證。

## 使用安全與可靠性

- demo 僅綁定 loopback，預設不開攝影機；停用時 video_feed 回傳 503。
- 進階串流端點仍需完整授權審查，勿直接對外提供服務。
- JSON 寫入採暫存替換，但鎖為單進程鎖；不保證多寫入者的一致性。
- 部分時間使用不含時區的 UTC，現有測試會提示棄用警告。
- 影像、模型與資料庫未隨 repository 提供；首次執行需準備資料和權重。

## 評估界線

API、幾何、時段測試通過不能取代人物偵測準確率評估。
目前未提供可公開重現的標註測試集、mAP、正式效能比較或學習成效實驗。
線段事件評估程式與模型 bbox 評估為不同工作，不應混用指標。

## 建議下一個里程碑

先補穩定的訊號有效期限、時段持久化與使用者隔離；
再用有授權的標註資料比較遮擋、光線、距離與模型大小。
若擴充動作分類，應另外定義類別、標註規則、訓練/測試切分及混淆矩陣。
