# 專題與驗證紀錄

## 研究問題與實作範圍

如何將影片中的人物偵測轉成可供應用程式使用的訊號？
本專案把預訓練 YOLOv8、ByteTrack、場域幾何事件、API、資料儲存
與網頁整合，並以 LearnSight 示範讀書時段與人物出現訊號的連接。

可展示的工程工作包括推論流程、事件處理、帳號權限、資料交換與 API 測試。
這些描述屬 repository 層級；團隊分工、個人貢獻及競賽紀錄
仍需作者依實際紀錄補充，不能只依程式規模推論。

## 功能狀態

| 項目 | 狀態 | 證據方式 |
|---|---|---|
| 本機影片人物偵測/追蹤 | 已有執行入口 | detect_demo.py，本機影片測試 |
| 線段/區域與校正 | 已有模組 | 幾何/校正測試；場景仍需自行設定 |
| 登入與 LearnSight API | 可測試 | test_public_release.py |
| 時段開始/同步/結束 | MVP | test_learnsight.py、LearnSight 網頁 |
| 學生動作分類 | 未完成 | 需姿態或動作資料與評估 |
| 與完整 AI 學習平台整合 | 待完成 | 需跨專案端到端流程 |
| 真實環境準確率 | 未驗證 | 需標註集、基準與錯誤分析 |

## 驗證紀錄

2026-09-06 前一輪本機公開測試：23 項通過。
涵蓋登入、未登入拒絕、無攝影機啟動、LearnSight
無資料回應、同步、結束、幾何與校正；不測模型準確率。

前一輪 yolov8m 本機管線記錄：約 10.68 秒處理 13 個影格、1.22 FPS。
硬體與完整設定未隨紀錄保存，僅供開發參考，不用作正式 benchmark。
公開入口預設使用 yolov8n，不能將兩者結果混為同一次實驗。

本次發布檢查的最新結果見 [release-validation.md](release-validation.md)。

## 建議展示順序

1. 介紹「人物出現訊號支援讀書時段」的問題與限制。
2. 啟動本機 API、登入、建立目標與時段。
3. 用有權使用的影片跑推論；展示人物框與追蹤 ID。
4. 同步到 LearnSight、展示回傳人數與時段狀態。
5. 結束時段，說明持久化與動作分類等待辦。
6. 展示測試結果，清楚區分自動測試、效能與準確率。

建議自行錄製 60–90 秒展示影片，附測試環境與個人分工說明。
公開截圖應使用本人或已有同意的影像；本次 repository 不附私人監視器素材。
